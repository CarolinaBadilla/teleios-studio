# Teleios Studio

Sistemas digitales diseñados con orden y propósito para comercios y profesionales.

## Identidad Visual
- **Estilo:** Sacro moderno (pureza, alabastro, orden arquitectónico).
- **Colores:** Blanco cálido (`#FAFAFA`), gris alabastro (`#F4F4F5`) y toques de orfebrería con bordes y halos dorados tenues (`amber-500/10` y `amber-900/15`).
- **Tipografía:** *Cinzel* (titulares solemnes serif) y *Plus Jakarta Sans* (cuerpo limpio sans-serif).

## Comandos

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la landing page.
